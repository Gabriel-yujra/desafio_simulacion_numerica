Sistemas de Ecuaciones Lineales

Optimización de redes de distribución, flujos de carburantes y análisis de sensibilidad social ($Ax = b$).

Modelo de Distribución

Se resuelve el sistema $Ax = b$ que balancea los flujos de combustible/alimentos desde plantas de acopio hacia zonas de la ciudad. Las variables $x_1, x_2, x_3$ pueden interpretarse como nodos de distribución en el área metropolitana La Paz–El Alto, donde los corredores de acceso desde el altiplano son susceptibles a bloqueos de rutas que reducen el flujo disponible.

  • x₁ — Flujo a la Zona Norte
  • x₂ — Flujo a la Zona Centro
  • x₃ — Flujo a la Zona Sur
  • x₄…xₙ — Nodos intermedios o reservas (si n > 3)
Qué significa cada método
  • LU — Plan estático ideal. Una pasada exacta; si falla hay ruta bloqueada.
  • Jacobi — Ajuste simultáneo de todos los nodos usando datos del turno anterior.
  • Gauss-Seidel — Igual que Jacobi pero cada nodo usa ya los datos recién actualizados → más rápido.
  • SOR (ω) — Gauss-Seidel acelerado: $\omega > 1$ "sobre-corrige" cada despacho para llegar antes al equilibrio.
  • Grad. Conjugado — Minimiza el costo cuadrático de transporte en ≤ n pasos. Ideal para redes grandes.
Estabilidad

Escenario F: Mal condicionado ($\kappa \approx 250$) → 5% de pánico desabastece la Zona Norte.
