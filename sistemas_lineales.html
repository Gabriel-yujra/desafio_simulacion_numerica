Sistemas de ecuaciones lineales

Abastecimiento y red de transporte

Una red de distribución de bienes puede representarse como un sistema Ax = b donde cada ecuación expresa la restricción de flujo en un nodo. Se implementan cinco métodos: LU (directo), Jacobi, Gauss-Seidel, SOR y Gradiente Conjugado. Los métodos iterativos garantizan convergencia si la matriz es diagonalmente dominante.

¿Qué se modela? La distribución de combustible y alimentos entre una planta central, depósitos intermedios y zonas de consumo, donde cada flujo debe satisfacer restricciones de balance. ¿Qué responde la simulación? ¿Cuántas unidades debe enviar cada nodo para satisfacer la demanda? Si la matriz converge rápidamente con Gauss-Seidel (pocas iteraciones, residuo bajo), el sistema de distribución está bien condicionado. Si no converge, indica desbalances en la red que requieren rediseño.
Parámetros del sistema
LU: exacto. Jacobi / GS / SOR: requieren dominancia diagonal. CG: para matrices simétricas definidas positivas.
